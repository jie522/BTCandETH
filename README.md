# ETHGRID 合約網格

手機瀏覽器就能用的 ETH / BTC 合約網格輔助工具,**搭配派網 Pionex 的合約網格使用**:
在這裡看行情與訊號、參考三檔建議參數,再到派網 App(合約網格 → 手動設定)自己填。

網址:<https://jie522.github.io/BTCandETH/>純靜態網頁(vanilla JS,無框架、無建置),
架構沿用 [羽球管理 APP](../260818%20羽球管理APP):`index.html` + `css/style.css` + `js/*.js` + PWA(可加到主畫面)。

## 功能

底部 5 個分頁:

| 分頁 | 內容 |
|---|---|
| 行情 | 即時報價(15 秒更新)、三週期共振、**網格勝率卡**(回放 5 年日線,依波動狀態 + 方向訊號統計 14 天沒被打出區間的比例)、方向判讀與依據 |
| 技術面 | 週期切換、投票、依實測重要度排序的技術指標(波動狀態 → 均線 → EMA 8/21/55 → ADX → 布林 → 成交量水位 → RSI → MACD);「技術面詳解」整頁:日線 / 週線操作建議、每日節點走勢、13 項指標詳細說明與實測 |
| 籌碼面 | 對網格的提醒(資金費率、恐懼貪婪,皆有 5 年實測依據)、資金費率 / 恐懼貪婪 / 期現溢價 / 大戶與散戶多空比 / 持倉量 / 主動買賣比;每項標明能不能信 |
| 建議 | 低 / 中 / 高風險三檔建議參數,各附強平距離與過去 30 天回測 |
| K 線 | 可滑動十字線的 K 線圖(均線可切 SMA 20/50/200 或 EMA 8/21/55、成交量與 20 根均量線、建議區間、支撐 / 壓力 S1/S2/R1/R2) |

設定(右上齒輪):ETH / BTC、深淺色、紅漲綠跌 / 綠漲紅跌、手續費、資金費率假設、維持保證金率。

## 資料來源

行情直接由手機瀏覽器抓交易所公開 API(不需金鑰):Binance 合約為主,失敗自動改用 OKX 永續。
派網的公開 API 不允許網頁跨網域讀取,所以不直接抓派網;派網合約價格與 Binance 非常接近,拿來判讀與回測沒有實質差異。
手續費預設用 0.05%(以派網費率估),可在設定調整。
你儲存的網格、設定都只存在自己手機的 localStorage,**不會上傳任何地方**。

## 本機測試

```bash
npx -y http-server -p 8092 -c-1 .
```

開 http://localhost:8092(手機版面請用瀏覽器開發者工具的手機尺寸看)。

## 部署到 GitHub Pages

1. 程式碼在 <https://github.com/jie522/BTCandETH>
2. <https://github.com/jie522/BTCandETH/settings/pages> → Source 選 **Deploy from a branch**,Branch 選 `main` / `(root)` → Save
3. 一兩分鐘後網址生效,手機打開 →「加入主畫面」

之後改動:`git add -A && git commit -m "說明" && git push`。
改了 CSS / JS 記得把 `index.html` 的 `?v=` 和 `sw.js` 的 `CACHE`、`ASSETS` 換成當天日期,手機才不會吃到舊快取。

## 重要限制(請讀)

- 訊號是**機率上的參考,不是預測**。強趨勢中網格會累積單邊虧損倉位。
- 強平價為簡化估算(逐倉、最壞情況、固定維持保證金率),實際以交易所為準。
- 回測是理想化:成交價 = 格線價、無滑價、資金費率用固定假設、假設掛單都排得到隊,實盤通常較差。
- 籌碼面只有資金費率、恐懼貪婪、期現溢價有完整歷史可回測;多空比、持倉量、主動買賣比 Binance 只公開 30 天,無法驗證,只當參考。
- 勝率卡與各指標的「實測」是 2021 ~ 2026 的 ETH / BTC 日線統計,相鄰天的窗口互相重疊,實際獨立樣本比天數少很多;只能當傾向,不是保證。
- 回測只代表過去那段時間,方向排名會隨行情變。
- 本工具不下單、不連交易所帳戶,不構成投資建議。
